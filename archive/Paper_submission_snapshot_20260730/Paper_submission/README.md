# TMM Submission Package

This directory is the upload-facing package for the current IEEE Transactions
on Multimedia submission.

## Files for ScholarOne

- `TMM_main_manuscript.pdf`: main manuscript PDF.
- `TMM_supplementary_material.pdf`: supplementary material PDF.
- `TMM_source_package.zip`: LaTeX source package for reproducibility or final
  source-file upload.

## Source Package Contents

The `source/` directory and `TMM_source_package.zip` contain:

- `main.tex`
- `content.tex`
- `supplementary.tex`
- `math_commands.tex`
- `reference.bib`
- `IEEEtran.cls`
- `IEEEtranN.bst`
- `figures/`

## Validation State

- Main manuscript page count: 12 pages.
- Supplementary material page count: 15 pages.
- Main manuscript target: TMM revised regular-paper boundary, within the
  14-page limit.
- Supplementary material is intended to be uploaded separately and is not part
  of the main-manuscript page count.

## Manual Items Before Upload

- Replace anonymous author metadata in `main.tex` if the submission is not
  double-blind.
- Confirm ScholarOne metadata: author list, affiliations, corresponding author,
  ORCIDs, funding statement, conflicts, keywords, and preprint links.
