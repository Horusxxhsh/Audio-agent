\section{Objective Metric Definitions and Protocol Notes}

This supplementary material uses the same operational objective metrics defined in the main paper. Briefly, \textbf{Param. Dist.} is computed as RMSE between flattened numeric parameter leaves (union of keys; missing numeric keys treated as zero; non-numeric leaves ignored), \textbf{Acc@0.1} is the fraction of flattened numeric parameters within $\pm 0.1$, \textbf{Recall} measures recall over active numeric parameters, \textbf{Cosine} is cosine similarity in the same flattened space, and \textbf{Module} is a schema-level Jaccard index over DSP modules inferred from the presence of keys ending in \texttt{On}. We do not apply per-parameter normalization, so RMSE magnitudes can be dominated by large-scale parameters.
Because these metrics are computed in parameter space, absolute magnitudes can depend on the protocol (split, candidate pool, and schema used to form predicted parameter dictionaries); we therefore interpret improvements \emph{within} each table under the stated protocol and avoid comparing magnitudes across tables.
