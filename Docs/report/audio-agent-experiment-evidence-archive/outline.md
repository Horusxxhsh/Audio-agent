## 结构检查

- 是否先给出一句话概述，让第一次阅读者能立刻建立全局？
- 是否明确写出目标、边界、价值和不做什么？
- 是否把背景、冲突、问题和回答分层说清楚？
- 是否在首次出现时定义了关键术语、概念或符号？
- 是否默认保留 `项目进度`，并把 repo 现状主要集中在该章节？
- 是否为关键机制、流程、架构或实验准备了图表？
- 最终成稿是否优先使用 TikZ 或 PGFPlots，而不是把 Mermaid 草图直接当成定稿图？

## 自检检查

- 是否检查了 XeLaTeX 编译 warning，而不只是看到 PDF 成功生成？
- 是否生成并查看了 `build/compile-review.md`？
- 是否生成并查看了 `build/self-check.md`？
- 是否清理了低信息密度句式，例如 `不是……而是……`？
- 是否检查了摘要、术语、图注、表头和正文口径是否一致？
