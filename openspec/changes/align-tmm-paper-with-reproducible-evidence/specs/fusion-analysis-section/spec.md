## 修改需求

### 需求：Sec 4.3 必须包含实际的 Fusion 权重分布数据
Sec 4.3 的融合权重统计必须来自当前仓库可复现工件，并在文中保留均值、标准差、最小值、最大值的对应关系。

#### 场景：权重统计复核
- **当** 读者核对融合权重统计表
- **那么** 数值必须能在 `Experiments/Fusion/fusion_beta_sensitivity.csv` 中逐列定位，且图文口径一致

### 需求：必须包含融合前后性能对比
融合性能对比必须基于可复现的 Text-only / Audio-only / Fusion 消融结果，且相对提升按同一口径计算。

#### 场景：融合增益声明
- **当** 文中声明 fusion 相比单模态的提升
- **那么** 必须使用 `Experiments/Fusion/fusion_beta_sensitivity.csv` 中同一行口径下的数据进行计算，不得混入其他不可复现来源的同名指标

### 需求：必须包含不确定性量化分析
不确定性量化分析必须建立在可复现的熵权重机制统计之上；若极端场景量化结果不可复现，只能作为定性讨论或未来工作。

#### 场景：讨论高/低不确定性场景
- **当** 文中解释“模态退化时权重迁移”
- **那么** 定量结论必须可由现有融合工件复核；无法复核的部分必须降级为定性结论

### 需求：必须验证温度参数 β 的影响
β 敏感性结论必须来自可复现 sweep 结果，并说明稳定区间和限制条件。

#### 场景：展示 beta sweep
- **当** 读者查看 β 从低到高的权重变化与性能变化
- **那么** 文中结论必须与 `fusion_beta_sensitivity.csv` 的趋势一致，并明确该结论仅在当前评估设置下成立
