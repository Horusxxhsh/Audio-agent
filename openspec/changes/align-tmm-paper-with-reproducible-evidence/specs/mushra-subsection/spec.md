## 修改需求

### 需求：论文必须包含完整的 MUSHRA 主观听测结果
MUSHRA 结果必须基于清洗后的原始评分数据统计，并与结果报告文件保持一致。

#### 场景：MUSHRA 总体统计核对
- **当** 文中报告被试人数、评分条目数和分组统计
- **那么** 统计必须与 `Experiments/mushura/mushra.csv` 在去除误入表头行后的计算结果一致，并与 `Experiments/mushura/results_report.md` 对齐

### 需求：必须包含 MUSHRA 方法论说明
方法论说明必须明确评分量表、试次分组、统计口径与清洗规则，确保第三方可复算核心统计和显著性结论。

#### 场景：复算 Trial 2-5 显著性
- **当** 文中给出 HCAP 与 manual 的显著性比较
- **那么** 读者应能基于清洗后的评分数据按被试内均值复算出一致的显著性结论

### 需求：图表必须符合 IEEE TMM 格式要求
MUSHRA 图表必须保持清晰编号、可读轴标签和足够分辨率，同时与文中统计口径一致。

#### 场景：图文一致性检查
- **当** 读者对照图表与表格中的 Trial 统计
- **那么** 图中样本分组与文中统计口径必须一致，且图表满足 IEEE TMM 的可读性要求
