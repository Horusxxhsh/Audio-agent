## 修改需求

### 需求：Sec 4.2 必须包含 TRR 与基线方法的定量对比
论文 Sec 4.2 的 TRR 对比表必须仅使用当前仓库可复现工件中的结果，并明确同表内指标的统一定义。

#### 场景：TRR 基线对比表呈现
- **当** 读者查看 Sec 4.2 的 TRR 与基线对比
- **那么** 表中数值必须来自 `Experiments/TextureResonance/texture_representation_comparison.csv`，且不得与其他章节不同尺度的同名指标混写为可直接对比结果

### 需求：必须包含 Wav2Vec2 层选择分析结果
层选择分析在主文与 supplementary 中必须引用同一结果来源并保持样本规模、最优层结论和趋势描述一致。

#### 场景：主文与补充材料交叉核对
- **当** 读者同时核对主文 layer sweep 段落与 supplementary layer 表
- **那么** 两者必须基于同一结果文件并给出一致结论，不得出现样本规模或最优层冲突

### 需求：必须更新测试样本数量描述
Sec 4.1 中关于测试样本和知识库规模的描述必须同时包含“总数据规模”和“评估子集规模”，并且算术一致。

#### 场景：实验规模解释
- **当** 论文描述 held-out 评估子集
- **那么** 必须明确总数据规模、子集规模和对应知识库规模之间的关系，禁止仅给出会造成误读的单一数字
