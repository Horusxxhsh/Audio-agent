## 新增需求

### 需求：关键量化结论必须具备仓库内证据追溯
论文中所有关键量化结论（摘要主结果、主表核心指标、鲁棒性结论、主观评测统计）必须能追溯到仓库内可访问工件，并且数值必须与工件一致。

#### 场景：审核摘要与主表数字
- **当** 作者在 `Paper/content.tex` 写入关键数字
- **那么** 每个数字必须能映射到现有仓库工件（CSV/MD/原始数据），且映射关系可被审稿或内部复核人员复算验证

### 需求：数据规模与拆分口径必须算术一致
论文必须对总样本数、测试子集规模和检索知识库规模给出算术一致且可复现的描述，禁止出现互相矛盾的规模叙述。

#### 场景：描述实验规模
- **当** 论文描述实验设置中的样本数与知识库规模
- **那么** 数值必须满足同一拆分规则下的算术一致关系，并与当前可加载数据资产一致

### 需求：同名指标必须使用唯一操作定义
同名指标（如 L2）在全文必须使用唯一操作定义；若存在不可避免的不同定义，必须改名并显式声明“不可直接横向比较”。

#### 场景：跨章节比较指标
- **当** 读者在不同章节看到同名指标
- **那么** 指标定义、尺度与计算口径必须一致，或被明确区分并禁止直接比较

### 需求：不可复现结论必须被降级或移除
任何依赖缺失工件、无法在当前仓库复算、或与现有工件冲突的量化结论，必须执行规范化处置（降级为定性、移除或移入 Future Work）。

#### 场景：发现缺失证据链
- **当** 复核发现某量化结论缺少可用证据文件或与现有工件冲突
- **那么** 该结论不得继续以定量结论出现，必须按处置策略调整并在文稿中保持一致
