## 修改需求

### 需求:实验 setup 描述必须与实现细节解耦
论文实验 setup 必须描述可复现实验协议与环境，不得出现脚本文件名、临时分析脚本或一次性工程命名。

#### 场景:方法段落审查
- **当** 读者阅读实验 setup
- **那么** 只应看到硬件、软件版本、协议和统计口径，不应出现 `profile.py` 等实现级文件名

### 需求:论文编译入口与文档结构必须稳定
`Paper/main.tex` 仍必须作为唯一正式编译入口；新增的回应文档与清单文档不得破坏论文编译流程。

#### 场景:编译与文档并存
- **当** 仓库新增审稿回应文档
- **那么** `latexmk -pdf Paper/main.tex` 的编译行为必须保持不变
