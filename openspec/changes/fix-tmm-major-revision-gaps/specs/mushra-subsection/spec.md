## 修改需求

### 需求:论文必须包含完整的 MUSHRA 主观听测结果
听测表格与图表必须保留，并与试次划分、样本数和统计口径保持一致；听测结论必须定位为“补充感知证据”。

#### 场景:听测结果呈现
- **当** 读者阅读 Trial 1、Trials 2-5、Trials 6-10 的结果
- **那么** 必须看到与各 trial 对应的统计表与图，且图文描述一致

### 需求:必须包含 MUSHRA 方法论说明
方法段落必须明确该实验为“hidden reference 的 multiple-stimulus 听测”，并清楚声明是否包含低质量锚点。

#### 场景:协议表述核验
- **当** 读者核对听测协议
- **那么** 不得将非标准设置错误表述为标准 MUSHRA

### 需求:术语必须区分 TRR 与 HCAP
客观检索实验中的 TRR 与主观听测条件中的 HCAP 必须明确区分，避免在同一结论中混用命名导致误读。

#### 场景:术语一致性检查
- **当** 读者跨章节阅读客观与主观实验
- **那么** 可以明确辨别 TRR（检索方法）与 HCAP（听测系统条件）的角色边界
