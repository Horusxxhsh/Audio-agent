## 新增需求

### 需求:回应与修订文稿必须使用 scientific-writing 流程生成
审稿回应文档与论文叙述性修订文本必须在执行阶段显式调用 `scientific-writing` skill 生成，输出必须采用学术段落体，不得以要点清单替代正文论述。

#### 场景:生成回应文稿
- **当** 作者编写 `Paper/TMM_Response_to_Reviewers.md` 或大段论文修订文本
- **那么** 必须先进入 `scientific-writing` 流程并按段落体完成写作

### 需求:scientific-writing 必须搭配证据核对步骤执行
`scientific-writing` 产出前必须完成与实验报告/统计工件的一致性核对，写作过程不得引入未经核对的新数字结论。

#### 场景:写作前核对证据
- **当** 作者准备写入定量结论
- **那么** 必须先完成对应证据核对并记录来源，再进入写作流程

### 需求:必须生成可投稿的逐条回应文档
变更必须产出面向审稿意见的逐条回应文档，并对每条意见给出“已完成修改”或“重投前计划”状态，不得只给泛化叙述。

#### 场景:回复 major revision
- **当** 收到 TMM 审稿意见后进行修订
- **那么** 必须生成 `Paper/TMM_Response_to_Reviewers.md`，且每条回复都能映射到论文章节或修订动作

### 需求:必须生成章节级修订清单
变更必须产出章节级修订清单，包含优先级、目标文件、验收标准与状态，确保后续实现可执行。

#### 场景:进入修订执行阶段
- **当** 研究者准备执行论文修改
- **那么** 必须存在 `Paper/TMM_Revision_Checklist.md`，并可用于逐项勾选追踪
