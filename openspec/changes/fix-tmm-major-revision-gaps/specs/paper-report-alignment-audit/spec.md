## 新增需求

### 需求:主实验结果必须通过逐项对齐审计
论文主实验表中的方法集合、指标集合与数值必须与指定实验报告逐项一一对应；若存在不一致，必须输出差异清单并在正文中修正或显式标注。

#### 场景:主实验表一致性核对
- **当** 作者更新 `Paper/content.tex` 主实验对比表
- **那么** 必须同时核对 `Experiments/AblationStudies/retrieval_comparison_report.md` 中对应行列，且方法与指标顺序、数值精度、最佳项标注保持一致

### 需求:审计结论必须区分一致项与差异项
一致性审计输出必须至少包含“一致项列表”和“差异项列表”；差异项必须给出定位信息与处理状态（已修复/待处理）。

#### 场景:存在来源冲突
- **当** 指定报告与 canonical Protocol-A 统计工件出现冲突
- **那么** 审计结果必须明确冲突位置，并禁止在论文中同时使用两套互斥数字作为事实结论
