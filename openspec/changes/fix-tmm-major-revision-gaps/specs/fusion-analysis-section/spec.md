### 需求:Sec 4.3 不得作为当前主结论证据链
在本轮修订中，fusion 相关量化结果禁止作为论文主实验结论依据；如保留相关文本，必须放在限制或背景讨论中，并明确“非本轮主证据”。

#### 场景:主结果叙事收敛
- **当** 读者阅读主实验章节的核心结论
- **那么** 不应看到 fusion 被用于支撑当前主结论的关键量化声明

### 需求:动态权重历史结果如被引用必须保持原值
若文稿在讨论性位置保留动态权重统计引用，则该引用必须保持既有统计值，不得在无新实验证据下改写。

#### 场景:检查权重统计引用
- **当** 读者在讨论或限制章节看到历史动态权重统计
- **那么** 该值必须与既有结果一致，不得出现未经证据支持的改动
