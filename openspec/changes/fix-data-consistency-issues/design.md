# Design: Fix Data Consistency Issues

## 上下文

当前论文存在多个数据一致性问题，主要源于：
1. 多次实验迭代导致数据源不同步
2. 手工维护的表格与实际 JSON/CSV 数据脱节
3. 论文修订时部分数值更新但其他位置遗漏

## 目标 / 非目标

**目标：**
- 统一所有实验数据在论文中的呈现，确保可追溯性和一致性
- 修复 Critical 和 High 级别的数据不一致问题
- 建立单一真相来源 (Source of Truth) 原则

**非目标：**
- 不重新运行实验（除非数据完全缺失）
- 不改变方法本身（TRR 仍然是 SOTA）
- 不添加新的实验场景

## 决策

### D1: Noisy Audio 统一数值策略

**问题**: 同一场景在论文中多处出现不同数值 (1.4964 vs 1.5180)

**决策**: 统一使用 `1.4964`

**理由**:
- supplementary.tex Table S9 使用 1.4964
- 与 Text-only baseline 的数值一致
- 最小化论文修改范围

**实施**:
- `content.tex:568` (robustness_noise table) → 1.4964
- `content.tex:583` (robustness_summary table) → 1.4964
- `content.tex:601` (dynamic_weight_strategy table) → 1.4964

### D2: β 敏感性问题解释策略

**问题**: 表格显示所有 β 值产生相同结果 (0.3056)，但正文叙述说 "β 增大会改变方差"

**决策**: 更新正文叙述，解释实际机制

**分析**:
- `quality_weight=1.0` 时，质量得分主导权重计算
- 熵权重退化为次要因素
- β 对最终结果影响被掩盖

**实施**:
- 更新 content.tex:516 叙述为："当 quality_weight=1.0 时，质量一致性主导权重分配，导致不同 β 值产生相同的融合结果"

### D3: 动态权重表保持现状

**问题**: weight 数值可能与实际计算不完全一致

**决策**: 保持当前表格，因为：
- 权重是动态计算的均值
- 数值在同一数量级 (0.4716)
- 不影响核心结论

### D4: 指标数量修正

**问题**: 正文写 "five metrics" 但实际定义 4 个

**决策**: 修正为 "four metrics"

**实施**:
- `content.tex:366` → "four operational metrics"

## 风险 / 权衡

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 修改可能引入新的不一致 | 论文可信度下降 | 每次修改后全文搜索相同位置 |
| β 敏感性分析显示"无效果" | 可能被质疑为无用分析 | 解释为质量主导的预期行为 |
| 原始数据文件可能不同步 | 长期维护困难 | 建议未来建立 CSV → LaTeX 自动生成 |
