## 为什么

IEEE TMM 审稿人关切 **C6: "复杂度与时延分析有明显疑点"** —— "表 III 的 'Audio scoring 1.369ms' 是 cache-only 情况，似乎不包含在线查询音频的 Wav2Vec2 前向 + Gram 构造...复杂度分析不可信"。本实验提供真实的端到端延迟测量，修正时延数据，回应工程实用性质疑。

## 变更内容

### 新增内容
- **End-to-End Latency Profiling**: 端到端延迟分析
  - 分模块计时：Wav2Vec2 编码、Gram 矩阵、KNN 检索、多模态融合、LLM 生成
  - 高精度计时：nanosecond precision (time.perf_counter_ns)
  - 区分可缓存部分（Wav2Vec2、Gram）和不可缓存部分（检索、融合、LLM）

### 简化设计（1周时间线约束）
- **最小可行版本**: 修正 Table III 数据即可
- **可选**: 完整 profiling（如果资源允许）
- **核心输出**: 更新的延迟表格和复杂度公式说明
