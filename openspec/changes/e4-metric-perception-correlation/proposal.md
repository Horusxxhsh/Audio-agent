## 为什么

IEEE TMM 审稿人关切 **C3: "指标设计存在系统性偏差"** —— "参数空间距离未必对应感知相似...未做按参数量纲/范围归一化...忽略非数值叶子/离散模式"。审稿人要求补充"感知对齐"的客观 proxy，并给出指标与听测的相关性分析。本实验通过计算 Spearman/Pearson 相关，验证参数指标与 MUSHRA 听测评分的关联，回应指标设计的合理性质疑。

## 变更内容

### 新增内容
- **Metric-Perception Correlation Analysis**: 指标与感知相关性分析
  - 计算 Spearman 和 Pearson 相关系数
  - 分析 L2 误差、Acc@0.1、余弦相似度与听测评分的关联
  - 识别"感知无关误差"（高参数误差但高听测评分的情况）

### 简化设计（1周时间线约束）
- **跳过**: 复杂的混合效应模型（受试者/查询的随机效应）
- **保留**: 基础相关分析（足够回应审稿人关切）
- **预期**: 中等相关性 (r = 0.5-0.7)，承认参数-感知映射的复杂性

## 功能 (Capabilities)

### 新增功能
- `metric-perception-correlation`: 指标与感知相关性分析模块
- `correlation-visualization`: 相关性可视化（散点图、热力图）
- `perception-independent-error-detection`: 感知无关误差检测

### 修改功能
- 无现有功能修改（纯数据分析）

## 影响

### 代码影响
- **新增文件**: `Experiments/E4_MetricCorrelation/correlation_analysis.py` (~350 行)

### 数据需求
- **MUSHRA 听测数据**: 需要原始评分数据（26 participants × N queries）
- **参数指标数据**: E1/E2/E3 实验产生的指标结果

### 计算资源
- **无 GPU 需求**
- **无 API 调用**
- **运行时间**: < 1 小时（纯统计计算）

### 论文影响
- **Sec 4.5**: 新增 "Metric Validation" 子节
- **补充材料**: 相关性分析表格
- **Response Letter**: 回应 C3 质疑，承认指标局限性并讨论改进方向

### 风险应对
| 相关性结果 | 应对策略 |
|------------|----------|
| r = 0.5-0.7 (中等) | ✅ 正常结果，讨论参数-感知映射复杂性 |
| r < 0.3 (弱相关) | ⚠️ 承认指标局限性，强调未来工作需要更多听测数据 |
| 负相关 | 🚨 检查指标计算是否有误 |

## 预期结果

### 成功标准
- Spearman/Pearson 相关系数显著 (p < 0.05)
- 识别 20-30% 的"感知无关误差"案例
- 中等相关性 (r = 0.5-0.7) 是可接受的，反映参数-感知映射的固有复杂性

### 可跳过条件
- 如果 MUSHRA 原始数据不可用，可跳过此实验
- 或在 Response Letter 中承认数据限制，承诺未来工作补充
