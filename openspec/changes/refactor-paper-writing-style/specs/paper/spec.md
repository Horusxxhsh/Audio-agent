# 论文写作风格和技术规范

## 修改需求

### 需求：使用流畅的段落式叙述
论文必须使用流畅的段落式叙述，避免使用要点列表（itemize/enumerate），除非在 Methods 章节中列出材料或试剂。

#### 场景：Introduction 章节不使用要点列表
- **当** 读者阅读 Introduction 章节
- **那么** 所有内容以段落形式呈现，不使用 itemize 或 enumerate 列表

#### 场景：Discussion 章节不使用要点列表
- **当** 读者阅读 Discussion 章节
- **那么** 所有内容以段落形式呈现，不使用 itemize 或 enumerate 列表

#### 场景：Conclusion 章节不使用要点列表
- **当** 读者阅读 Conclusion 章节
- **那么** 所有内容以段落形式呈现，不使用 itemize 或 enumerate 列表

#### 场景：Methods 章节可以使用要点列表
- **当** Methods 章节需要列出材料、试剂或设备
- **那么** 可以使用 itemize 列表，但仅限于这些特定情况

---

### 需求：明确定义所有缩写词
论文必须在首次使用每个缩写词时提供其完整定义，确保读者能够理解缩写的含义。

#### 场景：Abstract 中定义常用缩写
- **当** 读者阅读 Abstract
- **那么** DAW、DSP、RAG 等常用缩写在首次使用时明确定义

#### 场景：Introduction 中定义剩余缩写
- **当** 读者阅读 Introduction
- **那么** TRR、LLM 等缩写在首次使用时明确定义

#### 场景：全文使用一致的缩写定义
- **当** 读者阅读论文任何章节
- **那么** 所有缩写词使用一致的完整定义

---

### 需求：术语使用一致
论文必须使用一致的术语表述相同的概念，避免使用不同的术语指代同一事物。

#### 场景：Texture Resonance Retrieval 术语一致
- **当** 论文提及纹理共振检索
- **那么** 始终使用 "Texture Resonance Retrieval (TRR)" 这一表述

#### 场景：Dual-Modal Retrieval 术语一致
- **当** 论文提及双模态检索
- **那么** 始终使用 "Dual-Modal Retrieval" 这一表述

#### 场景：Vector-RAG 术语一致
- **当** 论文提及基于向量的检索
- **那么** 始终使用 "Vector-RAG" 这一表述，且仅在对比实验中使用

---

### 需求：适度使用主动语态
论文必须适度使用主动语态，避免过度使用被动语态，以提升可读性和生动性。

#### 场景：Related Work 章节使用主动语态
- **当** 读者阅读 Related Work 章节
- **那么** 大部分句子使用主动语态，如 "We propose"、"We demonstrate"

#### 场景：Method 章节使用主动语态
- **当** 读者阅读 Method 章节
- **那么** 方法描述使用主动语态，如 "We compute"、"We implement"

#### 场景：保持客观性
- **当** 使用主动语态
- **那么** 避免过度主观的表达，保持学术客观性

---

### 需求：完成所有图表
论文必须包含所有引用的图表，不能使用占位符或未完成的图表。

#### 场景：系统架构图完成
- **当** 论文引用系统架构图
- **那么** 图表必须完整绘制，无红色占位符

#### 场景：图表清晰可读
- **当** 读者查看任何图表
- **那么** 图表清晰、标签完整、分辨率足够（至少 300 DPI）

#### 场景：图表标题准确
- **当** 读者查看任何图表
- **那么** 图表标题简洁且信息丰富，准确描述图表内容

---

### 需求：实验结果包含统计信息
论文的所有实验结果表格必须包含统计信息（标准差或置信区间），以展示结果的稳定性和可信度。

#### 场景：主要实验表格包含标准差
- **当** 读者查看主要实验结果表格
- **那么** 每个数值包含标准差（使用 $\pm$ 符号）

#### 场景：关键结果包含显著性检验
- **当** 实验结果展示关键改进
- **那么** 添加显著性检验标记（*、**、***）并在标题中说明含义

#### 场景：单次运行说明局限性
- **当** 实验数据为单次运行
- **那么** 在表格标题中说明这是单次运行的结果，并讨论其局限性

---

### 需求：句子长度适中
论文的句子长度必须适中，平均长度控制在 15-20 词，避免超过 30 词的长句。

#### 场景：避免过长句子
- **当** 读者阅读论文
- **那么** 不存在超过 30 词的句子

#### 场景：句子长度适中
- **当** 统计论文句子长度
- **那么** 平均句子长度在 15-20 词之间

#### 场景：逻辑流畅
- **当** 拆分长句
- **那么** 使用连接词保持逻辑流畅，每个句子意思完整

---

### 需求：数学公式有解释
论文的每个数学公式后必须添加对变量含义和公式物理意义的解释。

#### 场景：关键公式有变量解释
- **当** 读者查看关键数学公式
- **那么** 公式后包含所有变量的含义解释

#### 场景：公式有物理意义说明
- **当** 读者查看数学公式
- **那么** 公式后包含公式的物理意义和作用说明

#### 场景：解释简洁明了
- **当** 添加公式解释
- **那么** 解释简洁明了，不冗长

---

### 需求：表格标题简洁且信息丰富
论文的所有表格标题必须简洁明了，同时提供足够的信息帮助读者理解表格内容。

#### 场景：表格标题简洁
- **当** 读者查看表格标题
- **那么** 标题简洁，不冗长

#### 场景：表格标题信息丰富
- **当** 读者查看表格标题
- **那么** 标题提供足够的信息，帮助理解表格内容

#### 场景：表格标题有说明
- **当** 表格需要额外说明
- **那么** 标题包含必要的说明文字

---

### 需求：段落过渡流畅
论文的章节和段落之间必须有流畅的过渡，确保逻辑连贯。

#### 场景：章节之间有过渡
- **当** 读者从一个章节进入下一个章节
- **那么** 章节之间有过渡句或过渡段落

#### 场景：段落之间有过渡
- **当** 读者从一个段落进入下一个段落
- **那么** 段落之间有过渡词或过渡句

#### 场景：逻辑连贯
- **当** 读者阅读论文
- **那么** 全文逻辑连贯，过渡自然

---

### 需求：引用格式统一
论文的所有引用必须使用统一的格式，避免混用不同的引用格式。

#### 场景：使用 \citet 格式
- **当** 在正文中引用文献
- **那么** 使用 `\citet` 格式（如 `\citet{stables2014semantic}`）

#### 场景：括号内使用 \citep 格式
- **当** 在括号内引用文献
- **那么** 使用 `\citep` 格式

#### 场景：引用格式一致
- **当** 读者查看所有引用
- **那么** 所有引用格式一致，无混用

---

### 需求：实现细节简洁
论文的 Method 章节必须聚焦于架构思想，避免过于详细的实现细节。

#### 场景：聚焦架构思想
- **当** 读者阅读 Method 章节
- **那么** 描述聚焦于架构思想和方法论

#### 场景：避免过于详细的参数
- **当** 描述实现细节
- **那么** 避免列出过于具体的参数（如缓冲区大小、端口号）

#### 场景：保留关键信息
- **当** 简化实现细节
- **那么** 保留关键信息，确保读者能够理解方法

---

### 需求：通过完整检查清单
论文必须通过完整的检查清单，确保所有写作规范都得到满足。

#### 场景：无要点列表
- **当** 运行检查清单
- **那么** 全文不使用要点列表（除 Methods 材料列表外）

#### 场景：缩写词已定义
- **当** 运行检查清单
- **那么** 所有缩写词在首次使用时明确定义

#### 场景：术语一致
- **当** 运行检查清单
- **那么** 术语使用一致，无歧义

#### 场景：被动语态减少
- **当** 运行检查清单
- **那么** 被动语态使用比例显著降低（至少减少50%）

#### 场景：架构图完成
- **当** 运行检查清单
- **那么** 系统架构图完成，无占位符

#### 场景：统计信息已添加
- **当** 运行检查清单
- **那么** 所有实验表格包含统计信息

#### 场景：句子长度适中
- **当** 运行检查清单
- **那么** 所有句子长度适中，无超过30词的句子

#### 场景：公式有解释
- **当** 运行检查清单
- **那么** 所有数学公式后有解释

#### 场景：表格标题改进
- **当** 运行检查清单
- **那么** 表格标题简洁且信息丰富

#### 场景：段落过渡流畅
- **当** 运行检查清单
- **那么** 段落过渡流畅

#### 场景：引用格式统一
- **当** 运行检查清单
- **那么** 引用格式统一

#### 场景：LaTeX 编译成功
- **当** 运行检查清单
- **那么** LaTeX 编译成功，无错误
