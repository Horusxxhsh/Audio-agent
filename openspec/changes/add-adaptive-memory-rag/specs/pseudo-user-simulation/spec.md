## 新增需求

### 需求:伪用户反馈模拟
评估环境必须包含一个数学定义的反馈函数，用于模拟人类对检索结果的微调过程。

#### 场景:模拟微调循环
- **当** 仿真脚本获得检索结果 $	heta_{ret}$ 后
- **那么** 它必须按照 $	heta_{new} = 0.5 	heta_{ret} + 0.5 	heta_{target}$ 生成“修正后”的参数，模拟用户向理想音色靠拢的行为

### 需求:自动化性能报告生成
评估系统必须能够自动运行多轮迭代并产出符合科研要求的 CSV 结果文件。

#### 场景:生成收敛曲线数据
- **当** 完成 5 轮“检索-微调-学习”循环后
- **那么** 系统必须产出一个 CSV 文件，记录每一轮的 L2 误差、余弦相似度和检索来源（KB vs Memory）
