# `modality-conflict-stress-test` 规范

## ADDED Requirements

### 需求:必须补充跨模态冲突（低熵但矛盾）stress 评测

论文必须补充“跨模态冲突”边界测试：文本与参考音频均呈现低不确定性（低熵），但语义目标相互矛盾。该评测必须在 held-out pool（N=211）上规模化运行（或提供可审计的构造与抽样规则），并报告融合权重与性能退化。

#### 场景:构造冲突条件并记录 α 分布

- **当** 作者为每个 query 构造一条与目标语义相反的文本描述（音频保持不变）
- **那么** 系统必须输出：
  - 融合权重 α（至少包含文本权重与音频权重）
  - α 的分布统计（mean/std 与分位数）
  - 与常规设置相比的性能退化（ΔL2、ΔAcc@0.1 等）

#### 场景:报告典型失败案例与边界讨论

- **当** 冲突 stress 评测完成
- **那么** 作者必须在论文或补充材料中给出至少 2–3 个代表性失败案例：
  - 冲突输入（文本与音频摘要）
  - 系统输出的参数摘要（或模块 ON/OFF）
  - 失败模式解释（平均化/偏置/不稳定等）
