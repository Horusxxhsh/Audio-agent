# `fusion-analysis-section` 规范（增量）

## MODIFIED Requirements

### 需求：Sec 4.3 必须包含实际的 Fusion 权重分布数据

论文 Sec 4.3 必须基于 held-out pool（N=211）报告融合权重（例如文本权重与音频权重）的经验分布，并区分至少三类设置：常规设置、单模态退化 stress（文本退化/音频退化）、以及跨模态冲突 stress。权重分布必须与对应性能指标一起呈现，避免“仅给公式不验证”。

#### 场景：权重分布统计与可视化

- **当** 读者阅读 Sec 4.3 Fusion 权重分析部分
- **那么** 必须看到：
  - 文本模态权重与音频模态权重的 `mean/std` 与分位数（至少 p25/p50/p75）
  - 在常规设置下的权重方差（用于支撑“接近静态/低方差”的边界表述）
  - 在 stress 与冲突设置下的权重偏移（用于支撑“优势主要来源于退化场景”的结论边界）
  - 图表数据来源（脚本与输出工件路径）

### 需求：必须包含融合前后性能对比

论文 Sec 4.3 必须在同一 protocol 内定量展示融合机制相比单模态方法的性能变化，并提供配对统计检验与 95% CI；禁止跨 protocol 横向比较绝对 L2。

#### 场景：同协议对比表格 + 统计检验

- **当** 读者阅读 Sec 4.3 融合效果对比表格
- **那么** 必须看到至少包含以下方法的对比（方法名可不同，但语义必须等价）：
  - Text-only
  - Audio-only
  - Fusion (entropy-conditioned reweighting)
- **并且** 表格必须包含：
  - 主指标 `L2` 的 mean±95% CI
  - paired 显著性检验的 p-value 与 Holm 校正后的 p-value（当存在多重比较）
  - `N=211` 的样本量声明与 protocol 标签（例如 Protocol-C）

### 需求：必须包含不确定性量化分析

论文必须展示熵（或等价不确定性度量）与权重分配之间的关系，并分别在单模态退化与跨模态冲突两类 stress 中解释其行为边界。

#### 场景：退化 vs 冲突的边界解释

- **当** 读者阅读 Sec 4.3 不确定性分析部分
- **那么** 必须看到：
  - 单模态退化（高熵）时权重如何向低熵模态偏移
  - 跨模态冲突（低熵但矛盾）时权重可能接近 1:1 的失败模式与性能退化证据
  - 对未来一致性检测/拒答策略的边界性讨论（不得将其写成已解决问题）

### 需求：必须验证温度参数 β 的影响

论文必须报告温度参数 β 的敏感性分析，并明确默认 β 的选择依据；该分析必须在可复现的协议与 split 下运行，并输出可追溯工件。

#### 场景：β sweep 的可复算结果

- **当** 读者查看 β sweep 相关结果（主文或补充材料）
- **那么** 必须看到：
  - 不同 β 值下的性能对比曲线/表格
  - 默认 β 的选择依据（以主指标 L2 为主，兼顾稳定性）
  - 工件来源（CSV/脚本）与 protocol 标签
