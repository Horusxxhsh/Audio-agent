# Texture Resonance comparison outputs

Historical comparison tables are kept by observed version rather than being
overwritten:

- `2026-02-17_texture_representation_comparison_n5.csv`
- `2026-02-28_texture_representation_comparison_n30.csv`

Future runs of `compare_texture_representations.py` write
`texture_representation_comparison.csv` in this directory. A new result must
include its run configuration and dataset/split provenance before replacing or
being compared with these historical outputs.
